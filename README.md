# 🚀 Migración WordPress a Astro (DAC Grupo)

Este proyecto es una reconstrucción moderna de la web de DAC Grupo, migrando desde un entorno monolítico de WordPress hacia una arquitectura de islas con **Astro**.

## 🛠️ Tecnologías utilizadas
- **Astro**: Framework principal para máxima velocidad.
- **TypeScript**: Para un código más seguro y mantenible.
- **Tailwind CSS**: Estilizado moderno y responsivo.
- **WordPress REST API**: Como fuente de contenido (Headless CMS).

## 💡 Desafíos superados
- Limpieza dinámica de shortcodes de **Visual Composer** mediante Regex.
- Segmentación de contenido monolítico de WP en secciones modulares de Astro.
- Gestión de variables de entorno para la protección de endpoints.
